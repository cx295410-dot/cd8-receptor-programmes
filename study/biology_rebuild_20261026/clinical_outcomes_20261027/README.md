# Exploratory clinical outcome extension

Three external bulk-expression cohorts extend the single-cell study: GSE78220 (author-recorded response and OS), GSE91061 (baseline response), and GSE135222 (baseline PFS). This is a post hoc exploratory extension. No programme association meets the BH threshold in the disclosed 24-test family. Eight tests of Memory/Dysfunction also do not meet the separate BH threshold. These analyses do not establish a clinical prediction model. Source patient data, downloaded expressions, clinical result rows and figures are not distributed in this code repository.

Set CD8_STUDY_ROOT to the biology_rebuild_20261026 output directory from the core analysis. Required upstream files are work/programme_definitions.json and multipanel_rebuild_20261026/references/clinical_raw_gene_feature_map.csv.gz. The latter is extracted from original gene features by the core pipeline and supplies Ensembl-symbol mapping; it is not inferred from clinical outcomes. Downloads and outputs stay under clinical_outcomes_20261027. Source terms continue to apply.

Run download_outcome_inputs.py, then clinical_outcomes.py, then verify_outcome_extension.py. The verification script also needs pdfplumber and the original Jung et al. supplementary PDF. Dependency versions are recorded in software_versions.json in the output. Statistical libraries include numpy, pandas, scipy, scikit-learn, statsmodels, lifelines, matplotlib and openpyxl. With local dependencies, clinical_outcomes.py uses its packages/ directory first; it also works with packages installed in an isolated environment. The --render-existing flag recreates figures and text from previously computed outcome tables; it does not recompute bootstrap intervals.

The main outputs include all-programme statistics, one-row-per-patient outcome tables, gene coverage, follow-up summaries, source concordance checks, two nine-panel figures in PDF/SVG/PNG/TIFF, and an English results draft. Higher-score response direction is fixed, not reversed when AUC is below 0.5. Kaplan–Meier median splits are descriptive; Cox models use continuous scores. Individual outcomes are neither imputed nor manufactured. GSE135222 durable clinical benefit is not treated as ORR. Exact time zero for the author-recorded GSE78220 OS field is not specified in its downloaded GEO characteristics and must remain qualified.
