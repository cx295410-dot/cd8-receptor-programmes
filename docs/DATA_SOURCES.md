Download links should be resolved from the GEO accession record and the original publication. Retain original library identifiers, barcodes and patient mapping. Source-specific annotations, public raw-count matrices, deposited TCR calls, breast antibody/isotype definitions and the original Caushi supplementary tables are required. Source tables include both primary tumours and other tissues; eligibility must use the recorded analysis definitions.

The full-gene follow-up requires the primary-resection raw GEX libraries and author-defined CD8 identifiers. Missing author patient identities are not reconstructed from filenames. Public deidentified source identifiers embedded in the code remain source identifiers, not inferred clinical labels. Files with individual measurements are deliberately not included in this code repository.

The original Hallmark GMT used by the analysis is MSigDB Hallmark2020. Retrieve the same collection through an authorized source and preserve its original terms; no third-party gene-set file is relicensed in this repository.
